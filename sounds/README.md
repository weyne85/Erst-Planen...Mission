# sounds/

Ablage für die `.ogg`-Sprachdateien der Mission (englisch). Die benötigten Dateinamen und Texte stehen in
`../README.md`, Kapitel 5, und im Abschnitt `SOUNDS` von `../scripts/00_config.lua`.

Die Dateien gehören in der fertigen `.miz` in den Ordner `TRN Sounds/`. Für Zone 2 wird zusätzlich der Ordner
`Airboss Soundfiles/` aus dem Moose-Soundpaket benötigt.
